AST SYMBOL → C++ NODE CLASS REFERENCE
======================================
"AST label" is what appears in the .outast file.
"C++ class" is the node type you implement visit() on in visitor.cpp.

Some labels are MISLEADING because the node's semanticMeaning is set
to a different string than its class name — those are called out explicitly.

================================================================================
STRUCTURAL / PROGRAM NODES
================================================================================
AST label       C++ class               Notes
-----------     -------------------     ----------------------------------------
[prog]          startNode               Root of the tree (not printed with a label)
prog            reptprog0Node           List of top-level class/impl/func defs
classdecl       classdeclNode           Class declaration
                                         children: id, isalist, {(reptclassdecl4)
{               reptclassdecl4Node      Member list inside a class body
isalist         optclassdecl2Node       Inherited class list (isa ...)
                reptoptclassdecl22Node  Additional ids in the isa list
impldef         impldefNode             Implementation block
                                         children: funchead, reptimpldef3
reptimpldef3    reptimpldef3Node        Statement list inside an impl body
funcdef         funcdefNode             Free function definition
                                         children: funchead, funcbody
funcbody        funcbodyNode            Body of a function (passAlong wrapper)
funcbody        reptfuncbody1Node       !! SAME LABEL — statement list inside body
                                            (reptfuncbody1 semanticMeaning = "funcbody")

================================================================================
NODES YOU NEED visit() IMPLEMENTATIONS FOR (semantic checking)
================================================================================
Priority order for a typical type-checking / symbol table pass:

  SYMBOL TABLE CREATION:
    classdeclNode        — declare class type
    funcdeclNode         — declare member function signature
    funcheadNode         — extract name, params, return type
    vardeclNode          — declare variable with type
    paramNode            — declare parameter
    impldefNode          — attach impl to class

  TYPE CHECKING:
    reptstatement4Node   — check LHS type == RHS type (assign)
    exprNode             — propagate type upward
    rightrecarithexprNode— check operand types for +/-/or
    rightrectermNode     — check operand types for *//and
    relexprNode          — check comparable types, result is bool
    aparamsandidNode     — check arg types match func signature (call)
    reptvariable2andidNode — resolve variable type, handle array indexing
    dotNode              — resolve member access type

  CONTROL FLOW / STATEMENTS:
    whilestatementNode   — condition must be bool
    ifstatementNode      — condition must be bool
    freturnstatementNode — return type must match funchead returntype
    readstatementNode    — variable must be readable type
    writestatementNode   — expression must be writable type
